# Technical Interview Prep, CodePath
An advanced course that refines technical interview mastery through complex Python challenges involving advanced data structures and algorithms. Follows an adaptive learning model that customizes the experience to the student's pace.

I'll be doing this to document my progress and development. Written in Python, but I might try to answer some of the questions in different languages for practice. 

# Course goals/learning outcomes

By the end of this course, I will (hopefully) be able to:
- Demonstrate mastery of advanced algorithmic techniques and analysis using the UMPIRE interview strategy
- Exhibit readiness for upper-level internship and entry-level software engineering interviews
- Apply complex problem-solving techniques to diverse, high-difficulty coding challenges with minimal guidance
- Develop awareness of tools and habits, including AI-assisted debugging and research, that support effective technical learning
- Clearly explain coding solutions and reasoning in interview-style settings

# Topics Covered

- Technical Interview Skills: UMPIRE interview strategy, communication, Big O analysis
- Core Data Structures: Applying strings, linked lists, dictionaries to solve complex problems
- Hash Tables & Heaps: Advanced hashing techniques, heap operations
- Stacks & Queues: Stack and queue data structures and operations
- Recursion & Memoization: Recursive functions, memoization techniques
- Trees: Binary trees, binary search trees, tree traversals
- Graphs: Graph representations, BFS, DFS, topological sort, Dijkstra's algorithm, union find
- Dynamic Programming: Memoization, tabulation, bottom-up, top-down, backtracking
- Greedy Algorithms: Introduction to greedy algorithm strategies
